## Build infrastructure

[sysnote8main](https://github.com/sysnote8main) contributed:

- The GitHub Actions build matrix for Minecraft 1.20.1, 1.21.1, 26.1.2 and 26.2, with matching JDK versions.
- Locked workflow dependencies and executable Gradle wrappers for Linux runners.
- Artifact filtering that excludes sources, Javadoc, development/shadow JARs, and `buildSrc` / `build-logic` outputs.

These contributions were already included in the initial public snapshot. This
credit makes their origin explicit without importing the previous repository's
Git ancestry or private operational records.
